# Build Files

As you know, this `IosevkaExtended` font is basically the **same** thing as the original one but just "_expanded_". The only thing that was changed was the width whereby it bumped up from `500` to `600`.

Below you are going to find the `private-build-plans.toml` file that was generated by [Iosevka Customizer](https://typeof.net/Iosevka/customizer) website.

```toml
[buildPlans.IosevkaExtended]
family = "Iosevka Extended"
spacing = "normal"
serifs = "sans"
noCvSs = false
exportGlyphNames = true

[buildPlans.IosevkaExtended.widths.Normal]
shape = 600
menu = 5
css = "normal"
```

> [!TIP]
> If you want to try making your own custom Iosevka fonts. I recommend you to take a look at the [Iosevka Font Customiser.md](https://github.com/Sunhaloo/IosevkaExtended/blob/main/learning/Iosevka%20Font%20Customiser.md) file found in this `learning` folder.

### The Screenshot Bash Script

- Here is the bash script that Claude generated for me:

```bash
#!/usr/bin/env bash

set -uo pipefail

FONT_FAMILY="Iosevka Extended"
FONT_FILE="/usr/share/fonts/IosevkaExtended/TTF/IosevkaExtended-Regular.ttf"
OUT_DIR="$HOME/Screenshots"

[[ -f "$FONT_FILE" ]] || {
  echo "font file not found: $FONT_FILE" >&2
  exit 1
}
command -v freeze >/dev/null || {
  echo "freeze not found in PATH" >&2
  exit 1
}
mkdir -p "$OUT_DIR"

flags=(
  --theme onedark
  --font.family "$FONT_FAMILY"
  --font.file "$FONT_FILE"
  --font.size 16
  --font.ligatures
  --line-height 1.4
  --window
  --padding 30
  --margin 30
  --border.radius 8
)

# one screenshot per main.<ext>
for f in main.*; do
  [[ -f "$f" ]] || continue
  ext="${f##*.}"
  echo "freeze $f -> $OUT_DIR/specimen-$ext.png"
  freeze "$f" "${flags[@]}" -o "$OUT_DIR/specimen-$ext.png" || echo "FAILED: $f" >&2
done

# character-set image: no window controls, bigger text
if [[ -f charset.txt ]]; then
  echo "freeze charset.txt -> $OUT_DIR/charset.png"
  freeze charset.txt \
    --theme onedark \
    --font.family "$FONT_FAMILY" \
    --font.file "$FONT_FILE" \
    --font.size 22 \
    --line-height 1.7 \
    --padding 40 \
    --margin 0 \
    -o "$OUT_DIR/charset.png" || echo "FAILED: charset.txt" >&2
fi

echo "done: $(ls "$OUT_DIR" | wc -l) files in $OUT_DIR/"
```

> [!WARNING]
> Again, the above bash script was generated with AI... But I did modify the original `FONT_FILE` and `OUT_DIR` variables as it was not what it was supposed to be.
>
> Yes, I did run this code on my machine because I **did read the code** and from what I am seeing; it did its job.
>

## Creation of Workflow File

> [!NOTE]
> I am going to take a lot of things from the following `build-font.yml` file which is found inside the [IoskeyleyMono](https://github.com/ahatem/IoskeleyMono) repository.
>
> > Link to `build-font.yml` file: <https://github.com/ahatem/IoskeleyMono/blob/main/.github/workflows/build-font.yml>

> [!WARNING]
> The `release.yml` file was made by basically following my notes, following the above mentioned `build-fonts.yml` file and also passing my original draft to AI.
>
> The code blocks that you see below are the **original** draft!
>
> > Meaning head over to the following [link](https://github.com/Sunhaloo/IosevkaExtended/blob/main/.github/workflows/release.yml) in order to view the actual `release.yml` file.

- Create the directory for GitHub Actions in the repository:

```bash
# create the release yaml file at the correct path
mkdir -p .github/workflows && touch .github/workflows/release.yml
```

- Setup the name and the event to run on:

```yml
# name of the workflow
name: Build and Release Font

# environment variables for the runners
env:
  # basically the build outputs says that `Node.js 20` is deprecated
  FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: true

# event for the workflow to act on
on:
  push:
    tags:
      - "v*.*.*"
```

- Setup the jobs that needs to be run by the runner:

```yml
# jobs run by the workflow
jobs:
  # linux build
  build-linux-release:
    runs-on: ubuntu-latest

    # change the permission so that we are able to save our files
    permissions:
      contents: write
```

- Here are the following steps that we are taking for setting up the runner ( _all of this is under the `jobs`_ ):

> Link to `setup-node` action: <https://github.com/actions/setup-node#usage>

```yml
# linux build
build:
  runs-on: ubuntu-latest

  # change the permission so that we are able to save our files
  permissions:
    contents: write

  # steps for the linux virtual machine / runner to take
  steps:
    - name: Clone our repository onto GitHub's virtual runner
      uses: actions/checkout@v7

    - name: Clone Iosevka official repository
      uses: actions/checkout@v7
      with:
        # details about the cloned repository
        repository: be5invis/Iosevka
        # pin down the version so that new changes does not affect build here
        ref: v34.9.0
        # the folder / directory for name for when cloning the original 'Iosevka' repositoy
        path: iosevka-src
        # following the official documentation by Iosevka
        fetch-depth: 1

    - name: Install required dependencies for font
      run: |
        sudo apt-get update
        sudo apt-get install -y fontforge python3 ttfautohint

    # following the official 'basic' setup guide from actions/setup-node README.md
    - name: Set up Node.js for the font building process
      uses: actions/setup-node@v7
      with:
        node-version: 24
```

- Build and verify the Iosevka Extended fonts:

```yml
- name: Build the Iosevka Extended Font
  run: |
    # refer to my 'Iosevka Font Customiser' markdown note inside of `learning`
    cp private-build-plans.toml iosevka-src/ && cd iosevka-src
    # install the required dependencies inside of Iosevka's repository
    npm install
    # command to build the 'hinted' and 'unhinted' fonts
    npm run build -- contents::IosevkaExtended

- name: Verify build output
  run: |
    DIST="iosevka-src/dist/IosevkaExtended"

    # check if the following directories exists inside the `$DIST` "folder"
    for dir in TTF TTF-Unhinted WOFF2; do
      if [ ! -d "$DIST/$dir" ]; then
        echo "IosevkaExtended $dir output not found!"
        exit 1
      fi
    done

    # use the `wc -l` command to count the number of font files in TTF
    ttf_count_hinted=$(find "$DIST/TTF" -name '*.ttf' | wc -l)

    # if any error occured!
    if [ "$ttf_count_hinted" -ne 27 ]; then
      echo "Expected 27 TTF files, found $ttf_count"
      exit 1
    fi

    # use the `wc -l` command to count the number of font files in TTF-Unhinted
    ttf_count_unhinted=$(find "$DIST/TTF" -name '*.ttf' | wc -l)

    # if any error occured!
    if [ "$ttf_count_unhinted" -ne 27 ]; then
      echo "Expected 27 TTF files, found $ttf_count"
      exit 1
    fi
```

- Package the fonts into their own `.zip` files:

```yml
- name: Package fonts release archives by zipping it
  env:
    VERSION: ${{ github.ref_name }}
  run: |
    DIST="iosevka-src/dist/IosevkaExtended"

    # hinted TTFs + license
    mkdir -p pkg-hinted/IosevkaExtended
    cp "$DIST"/TTF/*.ttf pkg-hinted/IosevkaExtended/
    cp LICENSE.md pkg-hinted/IosevkaExtended/
    (cd pkg-hinted && zip -r "../IosevkaExtended-${VERSION}-Hinted.zip" IosevkaExtended)

    # unhinted TTFs + license
    mkdir -p pkg-unhinted/IosevkaExtended
    cp "$DIST"/TTF-Unhinted/*.ttf pkg-unhinted/IosevkaExtended/
    cp LICENSE.md pkg-unhinted/IosevkaExtended/
    (cd pkg-unhinted && zip -r "../IosevkaExtended-${VERSION}-Unhinted.zip" IosevkaExtended)

    # web fonts: WOFF2 + license
    mkdir -p pkg-web/IosevkaExtended-Web
    cp "$DIST"/WOFF2/*.woff2 pkg-web/IosevkaExtended-Web/
    cp LICENSE.md pkg-web/IosevkaExtended-Web/
    (cd pkg-web && zip -r "../IosevkaExtended-${VERSION}-Web.zip" IosevkaExtended-Web)

    ls -lh IosevkaExtended-*.zip
```

- Create and _release_ the release:

```yml
- name: Create release and upload to releases section
  uses: softprops/action-gh-release@v2
  with:
    draft: true
    name: "Iosevka Extended ${{ github.ref_name }}"
    body_path: .github/release-notes.md
    files: |
      IosevkaExtended-${{ github.ref_name }}-TTF.zip
      IosevkaExtended-${{ github.ref_name }}-Web.zip
```
